# Güvenlik Politikası

IMAJER ayrıcalıklı erişim ve adli kanıt verisiyle çalışır. Güvenlik açığı
bildirimlerinde herkese açık issue içine hedef bilgisi, credential, private key,
ham kanıt veya müşteri verisi eklemeyin.

Bildirim için GitHub reposundaki **Security → Report a vulnerability** özel
bildirim kanalını kullanın. Bu kanal etkin değilse yalnız sorunun varlığını
belirten, sır içermeyen bir issue açın ve özel iletişim kanalı talep edin.

Desteklenen sürüm şimdilik en son `main` dalıdır. Proje geliştirme/laboratuvar
sürümüdür; `docs/PLAN_EKSIK_ANALIZI.md` içinde açık kalan üretim kabul maddeleri
tamamlanmadan mahkeme/üretim onayı verilmemelidir.
